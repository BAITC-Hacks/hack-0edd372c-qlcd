# hack-0edd372c-qlcd
Hackathon team repository for QLCD

## Умный подбор подрядчиков

React/Vite-клиент помогает организатору мероприятия выбрать до трёх подрядчиков. Он передаёт условия существующему Python backend и показывает его порядок, объяснения и причины отсева. Локального подбора, бронирования, оплаты и runtime-моков нет.

### Запуск frontend

Нужны Node.js 22.12+ и запущенный backend на `http://127.0.0.1:8000` ([его инструкция](backend/README.md)).

```sh
cd frontend
npm ci
npm run dev
```

Открыть **http://127.0.0.1:5173**. В PowerShell при ограничении запуска `.ps1` используйте `npm.cmd` вместо `npm`; менять ExecutionPolicy не нужно.

```sh
npm run lint
npm test
npm run build
npm run test:e2e
```

Unit-тесты выполняются без backend и сети. E2E требуют настоящий backend и Chrome, проверяют демо на широком и узком экране без перехвата ответов API.
